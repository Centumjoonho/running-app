나는 Expo React Native + TypeScript로 러닝 기록 앱을 만들고 있다.

현재 Expo 프로젝트 생성과 Expo Go 실행까지 성공했다.
이제 앱 기본 화면 구조부터 만들고 싶다.

앱 이름은 Run Shape이다.

이번 작업 목표:
- Expo Router 구조를 유지한다.
- 하단 탭 메뉴를 만든다.
- 홈, 러닝, 기록, 설정 화면을 만든다.
- 아직 GPS, Supabase, 지도 기능은 넣지 않는다.
- TypeScript 기준으로 작성한다.
- 디자인은 단순하고 깔끔하게 한다.

작업 방식:
1. 먼저 현재 프로젝트 구조를 확인해줘.
2. 어떤 파일을 수정하거나 생성할지 설명해줘.
3. 그다음 필요한 코드만 수정해줘.
4. 불필요한 파일 삭제나 큰 구조 변경은 하지 마.

대상 화면:

요구사항:

- 중앙에는 지도 영역처럼 보이는 회색 박스 표시

- 맨 아래에는 "러닝 시작" 버튼 표시

- UI만 만들어줘.

------------------------------------------------------------------
이제 Supabase 연결 준비를 해줘.

요구사항:
- @supabase/supabase-js 사용
- src/lib/supabase.ts 파일 생성
- 환경변수는 EXPO_PUBLIC_SUPABASE_URL, EXPO_PUBLIC_SUPABASE_ANON_KEY 사용
- .env.example 파일 생성
- 실제 키 값은 코드에 직접 넣지 마
- 아직 로그인 화면은 만들지 말고 Supabase 클라이언트 설정만 해줘.

[ 설치 ]

npm install @supabase/supabase-js
npx expo install @react-native-async-storage/async-storage
npm install react-native-url-polyfill
----------------------------------------------------------------------------

env -> 계정 입력
EXPO_PUBLIC_SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_여기에_복사한_값

Supabase Auth 기반 로그인/회원가입 화면을 만들어줘.

요구사항:
- 이메일 입력
- 비밀번호 입력
- 로그인 버튼
- 회원가입 버튼
- 로그아웃 버튼
- 로그인 상태를 유지해야 함
- 로그인하지 않은 사용자는 홈/러닝/기록 화면 접근 전에 로그인 화면으로 보내줘
- AsyncStorage 기반 세션 유지 설정을 적용해줘
- 에러 메시지는 화면에 표시해줘
--------------------------------------------------------------------
러닝 기록 앱용 Supabase PostgreSQL 테이블 SQL을 만들어줘.

필요한 테이블:
1. run_sessions
2. run_points

요구사항:
- Supabase Auth의 auth.users와 user_id로 연결
- run_sessions에는 시작시간, 종료시간, 거리, 시간, 평균 페이스 저장
- run_points에는 run_id, latitude, longitude, recorded_at, seq 저장
- RLS 활성화
- 사용자는 본인 데이터만 select/insert/update/delete 가능
- Supabase SQL Editor에 바로 붙여넣을 수 있게 작성해줘.

----------------------------------------------------------------------
러닝 시작/종료 기능을 추가해줘.

요구사항:
- 러닝 시작 버튼을 누르면 GPS 위치 추적 시작
- 위치가 변경될 때마다 좌표를 배열에 저장
- 지도에 Polyline으로 경로 표시
- 거리 계산은 Haversine 공식 사용
- 실시간으로 거리, 시간, 평균 페이스 표시
- 러닝 종료 버튼을 누르면 위치 추적 중지
- 아직 Supabase 저장은 하지 마
- 기록 데이터는 화면 상태로만 관리해줘

-------------------------------------------------------------
러닝 종료 시 Supabase에 기록을 저장하는 기능을 추가해줘.

요구사항:
- 현재 로그인한 user.id를 사용
- run_sessions에 러닝 요약 저장
- run_sessions 저장 후 생성된 id를 받아서 run_points에 좌표 배열 bulk insert
- 저장 성공 시 알림 표시
- 저장 실패 시 에러 메시지 표시
- 저장 중에는 버튼 비활성화

----------------------------------------------------------------
기록 탭에서 Supabase run_sessions 목록을 조회해줘.

요구사항:

- 날짜, 거리, 시간, 평균 페이스 표시
- 기록을 누르면 상세 화면으로 이동
