나는 Expo React Native + TypeScript로 러닝 기록 앱을 만들고 있다.

현재 Expo 프로젝트 생성과 Expo Go 실행까지 성공했다.
이제 앱 기본 화면 구조부터 만들고 싶다.

앱 이름은 Myle이다.

이번 작업 목표:
- Expo Router 구조를 유지한다.
- 하단 탭 메뉴를 만든다.
- 홈, 러닝, 기록, 설정 화면을 만든다.
- 아직 GPS, Supabase, 지도 기능은 넣지 않는다.
- TypeScript 기준으로 작성한다.
- 디자인은 단순하고 깔끔하게 한다.

작업 방식:
1. 먼저 현재 프로젝트 구조를 확인해줘.
2. 어떤 파일을 수정하거나 생성할지 설명해줘.
3. 그다음 필요한 코드만 수정해줘.
4. 불필요한 파일 삭제나 큰 구조 변경은 하지 마.

이제 Supabase 연결 준비를 해줘.

요구사항:
- @supabase/supabase-js 사용
- src/lib/supabase.ts 파일 생성
- 환경변수는 EXPO_PUBLIC_SUPABASE_URL, EXPO_PUBLIC_SUPABASE_ANON_KEY 사용
- .env.example 파일 생성
- 실제 키 값은 코드에 직접 넣지 마

[ 설치 ]

npm install @supabase/supabase-js
npx expo install @react-native-async-storage/async-storage
npm install react-native-url-polyfill
----------------------------------------------------------------------------

env -> 계정 입력
EXPO_PUBLIC_SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_여기에_복사한_값

러닝 기록 앱용 Supabase PostgreSQL 테이블 SQL을 만들어줘.

필요한 테이블:
1. run_sessions
2. run_points

요구사항:
- Supabase Auth의 auth.users와 user_id로 연결
- run_sessions에는 시작시간, 종료시간, 거리, 시간, 평균 페이스 저장
- run_points에는 run_id, latitude, longitude, recorded_at, seq 저장
- RLS 활성화
- 사용자는 본인 데이터만 select/insert/update/delete 가능
- Supabase SQL Editor에 바로 붙여넣을 수 있게 작성해줘.

문제:
- 상단의 Myle 앱 타이틀이 반쯤 잘려 보인다.

- 앱 실행 후 인트로/로그인/홈 화면 사이에서 화면이 계속 깜빡이는 것처럼 보인다.

가장 의심되는 원인:
- app/index.tsx 인트로 화면의 router.replace가 반복 실행됨
- app/_layout.tsx 또는 AuthProvider에서 인증 redirect가 반복 실행됨

- useEffect dependency 문제로 router.replace가 무한 반복됨
- 세션 loading 상태가 끝나기 전에 redirect가 실행됨
- 인트로 화면과 Auth Guard가 동시에 화면 이동을 처리함

요구사항:
1. 전체 라우팅 구조를 먼저 확인해줘.

   - app/_layout.tsx
   - app/login.tsx
   - app/(tabs)/_layout.tsx
   - AuthProvider 또는 SessionProvider 관련 파일
2. 현재 어떤 파일에서 router.replace, router.push, Redirect가 사용되고 있는지 찾아줘.
3. 중복 redirect가 발생하지 않도록 정리해줘.
4. 앱 시작 흐름은 아래처럼 고정해줘.

원하는 정상 흐름:
- 앱 실행

- redirect는 한 곳에서만 책임지도록 정리해줘.
- app/index.tsx에서 인트로 후 세션 확인과 이동을 처리한다면, app/_layout.tsx에서는 중복 redirect를 하지 마.

- Redirect URLs에는 아래가 등록되어 있음
  - myle://auth/callback
  - exp://192.168.100.208:8081/--/auth/callback

증상:

- Google 인증 진행

원인으로 의심되는 부분:
- Supabase signInWithOAuth에 options.redirectTo가 제대로 전달되지 않음
- redirectTo 값이 Supabase Redirect URLs와 정확히 일치하지 않음
- redirectTo가 없거나 불일치해서 Supabase Site URL인 localhost로 fallback됨
- WebBrowser.openAuthSessionAsync의 returnUrl과 Supabase redirectTo가 다름
- Linking.createURL 결과가 예상과 다르게 localhost로 생성됨

   - 개발 빌드/실제 앱 환경에서는 myle://auth/callback 형태
4. WebBrowser.openAuthSessionAsync(data.url, redirectTo)의 두 번째 인자도 signInWithOAuth에 넣은 redirectTo와 완전히 동일하게 해줘.

   - redirectTo
